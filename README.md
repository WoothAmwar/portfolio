# Anwar Kader Portfolio Website
This is my portfolio website, built with AnimeJS and React. 

You can run this locally by running `npm install` to download any and all node packages, and `npm run dev` to run this on the default port (300))

---

I used various tools and websites for the assets contained in this website, including but not limited to
- https://www.favicon.cc/
- https://animejs.com
- https://infleqtion.com/media-kit/
- Custom application to create the desk image (built with ImageJS, OpencvJS, and MobileSAM, with client-side only processing)
